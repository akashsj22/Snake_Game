# 🐍 Snake Game

A classic Snake Game built using Python and Tkinter.

---

## 🚀 Features

- Smooth snake movement
- Food spawning system
- Score tracking
- Collision detection
- Game over screen
- Keyboard controls
- Responsive gameplay

---

## 🛠️ Technologies Used

- Python
- Tkinter
- Random module

---

## 🎮 Controls

| Key | Action |
|---|---|
| ⬆️ Up Arrow | Move Up |
| ⬇️ Down Arrow | Move Down |
| ⬅️ Left Arrow | Move Left |
| ➡️ Right Arrow | Move Right |
